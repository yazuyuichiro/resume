## プロジェクト実績（抜粋）

### 【本業】データ分析プロジェクトの推進
- 顧客対応：課題のヒアリング、要件の整理、進捗・結果の報告
- プロジェクト設計：目的に合わせた分析方針・進め方の設計
- データ分析：データの収集・前処理・集計・可視化
- モデリング：機械学習モデルの構築・評価
- プロジェクトマネジメント：スケジュール管理、関係者との調整、進行管理
- 年間10〜20件のプロジェクトに参画（1案件2〜3か月、3〜5名体制）
- クライアントは官公庁4割・民間6割、民間は金融・鉄道・自動車などの大手企業が中心
- 1回あたり約1,000人が参加するコンペティションに関連する分析・結果報告も担当
- 生成AI活用の支援プロジェクトでは、対象業務の工数を30〜40%削減した事例がある
- 実践型研修の講師として年間10〜20回登壇（1回約30名、営業職などの初学者から上級者まで幅広く対応）

### 【副業】生成AI活用の講師・研修設計

- 対象者のレベルや目的に合わせた研修設計（カリキュラム設計、教材・演習の作成）
- AI勉強会の運営・登壇
- Web制作会社の研修事業を支援する形で初学者向け研修を実施（1回約15名、プロジェクト全体では40名規模の研修案件）

### 【副業】特定企業向けAI導入コンサルティング・伴走型ツール開発
- 週次定例MTGを実施し、現場の課題ヒアリング、AI活用のアドバイス、社内リテラシー向上のための教育を牽引
- ヒアリング内容を基に、以下の各種ツールの要件定義・アーキテクチャ設計・プロトタイプ実装・改善をアジャイルに実行
  - 生成AIを活用したコンテンツ生成Webアプリのプロトタイプ開発
  - ブラウザ自動化およびスクレイピングによる営業・情報収集プロセスの自動化システム
  - 社内リテラシー向上を目的としたAI・IT関連教材の作成
- **使用技術：** Python, Streamlit, OpenAI API, Anthropic API, Gemini API, Claude Code, Gemini CLI

### 【本業】生成AIを活用した社内・顧客向けシステム開発（PM・実装）
- LLMを活用したテキストデータの自動評価・分析システムの開発
- 独自アルゴリズムを用いたマッチングシステムおよび自動データ生成ツールの開発
- 業務効率化に向けた画像処理AIパイプラインの構築
- **使用技術：** Python, 各種LLM API, データ分析系ライブラリ

### 【副業】ヘルスケア領域の実データを用いた予測モデル構築

- 特徴量選択、機械学習モデル構築、交差検証（K-Fold・LOOCV）、古典的統計解析との比較
- **使用技術：** Python, scikit-learn, 統計解析ツール

### 【個人開発】AIエージェント活用・データ分析
- AIエージェントを用いた自動情報収集および動画・コンテンツ作成ツールの構築
- スポーツデータの収集・統計分析および可視化
- **使用技術：** Python, Claude Code, Gemini CLI, Cursor

### 【個人開発・運営】Webアプリ「yason-eng」
- 登録不要で、データを預からないWebアプリを作る取り組みを開発・運営（ https://yason-eng.com/ ）。データはブラウザの中だけで処理し、サーバーに送りません。「預からないから、漏れない」が合言葉です。会員登録不要・インストール不要で、すべての機能を無料で提供
- 現在のラインナップはギター向け。簡易DAW「ふりぃだう」：ブラウザだけでギター・ボーカルの録音、重ね録り、ミックス、WAV／MP3書き出しができるWebアプリ。BPM自動検出、イコライザー・コンプ・リバーブ・ディレイ、チューナーを搭載
- TAB譜動画作成「たぶめいかぁ」：演奏動画に重ねるTAB譜・コード・歌詞の横長動画を作成し、MP4（60fps）で書き出し
